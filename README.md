# b2t

10進数・2進数・16進数のバイト列とUTF-8テキストを相互変換するCLIツール。

## 使い方

```console
$ b2t 65 0b01000010 0x43
"ABC"

$ b2t -r "ABC"
0x41 0x42 0x43

$ b2t -rb "AB"
0b01000001 0b01000010

$ b2t --reverse --dec "AB"
65 66

$ b2t 0xE3 0x81 0x82
"あ"
```

標準入力にも対応しています。詳細は`b2t -h`を参照してください。

逆変換（`-r` / `--reverse`）の出力基数は次のオプションで選択できます。

| オプション | 出力形式 |
| --- | --- |
| `-x`, `--hex` | 16進数（既定）。`0x`付き2桁 |
| `-d`, `--dec` | 10進数。ゼロ埋めなし |
| `-b`, `--bin` | 2進数。`0b`付き8桁 |
